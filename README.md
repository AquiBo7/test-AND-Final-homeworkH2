# 校园学科竞赛与组队中心 (期末大作业)

这是本课程的期末大作业项目。本项目是一个面向校园学生的学科竞赛信息聚合平台，旨在解决竞赛信息零散、历年数据不透明等问题。

##  核心功能
*   **近期竞赛大厅**：支持按竞赛类别（计算机类、理科类、商科类）动态筛选和瀑布流展示。
*   **历年数据看板**：集成 ECharts，可视化展示历年核心赛事人数趋势与大类占比。
*   **3D 荣誉殿堂**：基于 A-Frame 搭建的虚拟 3D 展厅，支持第一人称漫游与奖杯交互展示。

##  技术栈
*   **前端结构与样式**：HTML5, CSS3, Bootstrap 5.3
*   **交互与逻辑**：原生 JavaScript (ES6)
*   **数据可视化**：Apache ECharts 5
*   **3D Web 引擎**：A-Frame 1.4.2
*   **数据源**：本地静态 JSON 文件（`fetch` 异步读取）

##  运行说明 (重要)
由于本项目使用了原生 `fetch` API 异步读取本地的 `data.json` 数据，受浏览器同源策略安全限制，**请勿直接双击打开 `index.html`**，否则会产生跨域报错导致数据无法加载。

1. 克隆或下载本项目到本地。
2. 使用 Trae 或 VS Code 打开项目文件夹。
3. 在编辑器扩展商店中安装 **Live Server** 插件。
4. 右键点击 `index.html`，选择 **"Open with Live Server"**，系统将自动在浏览器中完整运行项目。
